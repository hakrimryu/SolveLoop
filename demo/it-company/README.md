# 架空IT企業の初期ナレッジ

`knowledge.json` は株式会社 柳を想定した日本語の合成社内文書50件です。実在企業の資料や規程を転用したものではありません。ツール名、窓口、申請期限、業務運用はデモ用の設定です。メールアドレスは例示用ドメインを使用しています。

| 管理部門 | 件数 | 内容 |
| --- | ---: | --- |
| IT | 28 | 端末・認証・開発・権限・運用・情報管理 |
| 人事 | 8 | 勤怠・休暇・在宅勤務・育成・個別相談 |
| 総務 | 7 | 入館・会議室・備品・発送・届出・防災 |
| 経理 | 7 | 経費・出張・購買・カード・支払・工数・請求 |

各文書は適用対象、目的、4段階の手順、例外、問い合わせ時の必要情報、担当窓口、改定日を含みます。本文は既存画面のプレーンテキスト表示に合わせています。現実の契約・就業規則・製品設定の判断には使用しません。

これは問い合わせ0件から操作を始めるための文書セットです。既存の `demo/manifest.json` を使う100件問い合わせシナリオとは独立しており、従来のデモ・評価入力を変更しません。既存の `app.demo load/reset` の入力ではありません。

このファイルを置いただけではDBは変更されません。既存DBへの置き換えは、対象と削除範囲を明示した承認、復旧用バックアップ、アプリケーションの書き込み停止を伴う管理作業です。初期公開状態を取り込む場合は、イベントに `synthetic_initial_seed` とこのデータセットの版を記録し、実際の人による承認・解決実績と区別します。検索ベクトルは実際のローカルOllamaで準備します。
